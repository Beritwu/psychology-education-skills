# Changelog

## 0.1.0 — Public preview

- Evidence-aware course production with static and dynamic planners.
- 22 built-in skills and an optional pinned 14-skill Education Agent Skills provider.
- Revision-aware edits, quality gates, editable PPT support and draft/formal exports.
- Benchmark scaffolding and revision-bound human evaluation.
- Chinese, English, Japanese and Korean project introductions.
- A classical-conditioning sample lesson and accessible interactive animation.
- Installation, API, operations, contribution, security and license documentation.

This is a public preview. M6 production validation is incomplete: three real-course
teacher evaluations and the complete comparable live benchmark matrix are pending.
Historical benchmark reports are retained as development evidence, not efficacy claims.
