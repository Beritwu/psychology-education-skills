## Learning purpose

Identify NS, US, UR, CS and CR across before-conditioning, pairing, and tone-alone
test phases. Explain that stimulus/response labels depend on the learning history
and eliciting stimulus. The teaching duration is 20 minutes, not an experiment's
duration. Diagram timings and repetitions are schematic, not measured data.

## How skills were used

1. The PEBS dynamic runtime actually executed `backwards-design-unit-planner`
   and created a learning-design artifact. Research budget prevented claim
   verification, so dependent steps stayed blocked.
2. The authoring assistant read and applied that skill plus the pinned
   `hinge-question-designer` and `dual-coding-designer` instructions to produce
   the separately labeled example package. The design record shows their outputs.
3. The assistant implemented the HTML animation from the storyboard and checked
   browser behavior. This does not change PEBS's video-rendering boundary.

The example is not imported into the production Store as SUPPORTED evidence,
does not carry a teacher signature, and does not count toward M6 real-course
acceptance. The animation design review is an assistant judgment, not a G6 runtime
PASS or a teacher finding. Use the static overview when motion is unnecessary.

## Playback controls

Play/pause controls a single continuous clock. Drag the timeline to compare any
moment; phase buttons and Previous/Next jump to meaningful instructional stops.
The two on-page exercises explain each answer choice and transfer the labeling
rule from a sound to a light. All controls and feedback support four languages.
