# 心理学证据判读候选集

`evidence-judgment-candidates.json` 是按三单元各四个概念准备的24条候选判断：每个概念一条拟由引文支持的陈述及一条拟不由引文推出的陈述。每条绑定内容包文件哈希、版本、教材快照哈希、原文定位与概念ID。

候选标签均由构建者提出，状态为 `DRAFT_UNREVIEWED`，不等于教师裁决、研究结论真实性判定或已验证的评分标准。题目只问给定引文是否足以支持陈述；“引文不能推出”不等于证明陈述为假。引文之外的背景和人群外推不能被偷偷当作给定证据。

`evidence-review-form.yaml` 是绑定候选集文件SHA的空白教师审核表。教师可复制表格，逐条对照候选集中的陈述和引文，填写实际审核人、日期、判断与依据；未审核的条目保持空白。候选集变化后须重新核对哈希并导出新的空表，不能将旧表套用到新版本。

12条开发候选与12条保留候选按概念隔离；固定教材仍可能跨概念重复。保留集在教师完成独立核对之前不用于调节提示、阈值或模型选型。应由具备相关学科知识的真人审核每条引文定位、陈述、拟议判断和歧义，保留分歧与修改记录；必要时补充可靠来源或删除不合格题目。标签经审核后再冻结版本和哈希，并在实现正式评估器后报告逐类误报、漏报、样本量与复现配置。

当前项目未因候选集自动更改证据门禁，也未将候选结果写为真人审核或课堂成效。课程使用的实际引用仍走项目证据核验路径。
