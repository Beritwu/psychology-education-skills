以下只按题干与选项文本核对，不假定各 `misconception` ID 的外部定义；涉及 ID 时，按选项文本反推其指向。

**1. `extinction-application-1`**
- **答案核对**：A 与题干一致。题干只给出“已习得→单独呈现→反应减少”，不能据此推出“原学习被彻底删除”。
- **误解引用**：B“彻底删除”对应 `extinction-1`；C“此前根本没有习得”对应 `extinction-2`，文本上能对应。
- **具体问题**：C 与题干“已习得”直接冲突，不是从记录中可能得出的结论，只能筛出没读题干的人；若 `extinction-2` 就是这个误解，本题无法可靠诊断。`rationale` 也承认“题干已给出先前习得”，等于自证 C 无效。另 `assessment.misconception_ref` 只指 B，未覆盖 C。
- **结论**：答案无误；C 是无效干扰项，引用覆盖不全。

**2. `generalization-application-2`**
- **答案核对**：A 方向可成立，但措辞偏弱。题干已明确“对另一种声音没有作出反应”，所以更准确的说法是“记录表明并非所有声音都引出反应”，而不是“不能推断所有声音都引出反应”。
- **误解引用**：B 对应 `generalization-1`，C 对应 `generalization-2`，文本上能对应。
- **具体问题**：B“所有声音必然……”和 C“无法辨别任何声音”都被题干最后一句话直接否定。学生只要读到“对另一种声音没有作出反应”，就能排除 B、C，因此本题无法可靠诊断这两个泛化误解。
- **硬伤**：`rationale` 说“其他声音的反应未报告”，与题干“对另一种声音没有作出反应”直接矛盾/至少不准确。
- **结论**：A 不算错，但题干、选项、理由不一致，需修改。

**3. `negative-reinforcement-application-1`**
- **答案核对**：A 与题干一致。“移除遮罩”＋“按键从每轮 2 次升到 6 次”＋“相同机会数”支持“移除刺激且同一行为增加”的负强化观察模式。
- **误解引用**：B 对应 `negative-reinforcement-1`（把移除直接当惩罚、忽略行为变化）；C 对应 `negative-reinforcement-2`（把“负”当“坏”，推成负惩罚），文本上可对应。
- **具体问题**：B、C 都落在“移除/负＝惩罚”这一大类，区分度有限；`assessment.misconception_ref` 只指 B，C 的目标未在 assessment 级体现。题干未说明遮罩是否厌恶刺激，但 A 用“观察模式”措辞已避免绝对化，因此不算硬伤。
- **结论**：基本成立；干扰项重叠、引用粒度有问题。

**4. `positive-punishment-application-2`**
- **答案核对**：A 与题干一致。“加入闪框”＋“提前点击从每轮 7 次降到 3 次”支持正惩罚的观察模式。
- **误解引用**：B 对应 `positive-punishment-1`；C 对应 `positive-punishment-2`，文本上可对应。
- **具体问题**：B、C 实质都是“正/加入＝强化”，重叠明显；且题干已给出“行为减少”，B“无须观察行为变化”被直接反驳。`assessment.misconception_ref` 只指 B，未覆盖 C。
- **结论**：答案正确；干扰项独立性和引用覆盖需调整。

**5. `correlation-application-1`**
- **答案核对**：A 与题干一致，但几乎是题干复述：观察研究、未操纵睡眠、未排除其他因素→只能支持相关，不能确认因果。
- **误解引用**：B 对应 `correlation-1`（把相关当因果）；C 对应 `correlation-2`（相关即排除其他解释），文本上可对应。
- **具体问题**：题干“未操纵睡眠或排除其他因素”已直接否定 B、C，答案过度明显，诊断效度低。这不是答案错误，而是题干泄题、区分度低。`assessment.misconception_ref` 只指 B。
- **结论**：逻辑无错；题目过易，难以诊断误解。

**6. `random-assignment-application-2`**
- **答案核对**：A 基本成立：随机数分配＝随机分配；题干未说从目标人群随机抽样。但“自愿报名”其实已表明是自选样本，A 说“题目未说明”偏弱，严格应说“自愿报名不是从目标人群随机抽样”。
- **误解引用**：B 对应 `random-assignment-1`（随机分配＝随机抽样）；C 对应 `random-assignment-2`（随机分配＝基线完全相同），文本上可对应。
- **具体问题**：B 被“自愿报名”直接削弱/否定，提示过强；C 是较合理的概念干扰项。`assessment.misconception_ref` 只指 B，未覆盖 C。
- **结论**：答案可成立；A 措辞可更精确，B 有过强提示。

**跨题问题**
- 六题正确项均为 A，存在明显位置偏差。
- 六题的 `assessment.misconception_ref` 都只指向第一个错误项 B，而 C 另有 `misconception_ref`；若运行时用 assessment 级字段诊断或追问，选 C 会被误归因。除非运行时优先读取 `option_details`，否则这是系统性引用问题。
- 多题题干直接否定误解项（如 1C、2B/C、5B/C、6B），使题目更像阅读理解而非误解诊断。
- 最明确的硬伤是第 2 题 `rationale` 与题干矛盾；其次是第 1 题 C 与“已习得”前提冲突。
